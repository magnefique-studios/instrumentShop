## PostgreSQL (instruments service)

### Table: instruments_for_sale

**Source**: `db/sql/instruments-latest.sql`

```sql
CREATE TABLE IF NOT EXISTS instruments_for_sale(
   ID              VARCHAR(50) NOT NULL PRIMARY KEY,
   Title           VARCHAR(140) NOT NULL,
   Sub_title       VARCHAR(58) NOT NULL,
   Price           VARCHAR(12) NOT NULL,
   Instrument_Type VARCHAR(29) NOT NULL,
   Condition       VARCHAR(4) NOT NULL,
   Location        VARCHAR(33) NOT NULL,
   Post_URL        VARCHAR(114) NOT NULL,
   Seller_type     VARCHAR(14) NOT NULL,
   published_date  VARCHAR(14) NOT NULL
);
```

**Records**: 131 instruments (Sri Lanka marketplace data — Colombo, Gampaha, Kandy, etc.)
**Init**: Loaded via Docker entrypoint at `/docker-entrypoint-initdb.d/instruments-latest.sql`

### Table: instruments_for_sale_chicago

**Source**: `db/sql/instruments-chicago.sql`

```sql
CREATE TABLE IF NOT EXISTS instruments_for_sale_chicago(
   ID              VARCHAR(50) NOT NULL PRIMARY KEY,
   Title           VARCHAR(140) NOT NULL,
   Sub_title       VARCHAR(58) NOT NULL,
   Price           VARCHAR(12) NOT NULL,
   Instrument_Type VARCHAR(29) NOT NULL,
   Condition       VARCHAR(4) NOT NULL,
   Location        VARCHAR(33) NOT NULL,
   Post_URL        VARCHAR(114) NOT NULL,
   Seller_type     VARCHAR(14) NOT NULL,
   published_date  VARCHAR(14) NOT NULL
);
```

**Records**: 86 instruments (same structure as main table)
**Init**: Loaded via Docker entrypoint at `/docker-entrypoint-initdb.d/instruments-chicago.sql`
**Note**: Used in cartesian product query when location="Chicago" — `SELECT * FROM instruments_for_sale, instruments_for_sale_chicago` produces 131 × 86 = 11,266 result rows.
